================================================================================
SASSY STRIDES — RAW HTML BACKUP FOR STATIC PAGE TEMPLATES
================================================================================

How to use this file:

1. In wp-admin, go to Pages and open (or create) the Page with the slug
   noted below each section (About = /about, Advertise = /advertise, etc).
2. Add a "Custom HTML" block to that Page's content.
3. Copy everything between the "===== START =====" and "===== END ====="
   markers for that page and paste it into the block.
4. Publish/update the Page.

Notes:
- All URLs below are site-relative (e.g. "/fashion/") so they'll work on
  any domain (staging, production, etc.) without editing.
- The Contact page block includes the literal Forminator shortcode
  [forminator_form id="1669"] — WordPress still processes shortcodes
  inside Custom HTML blocks because the whole page content passes through
  do_shortcode() via the_content(), so this will render the real form.
- The FAQ accordion's open/close behavior still works after pasting this,
  because assets/js/faq-accordion.js targets the same class names
  (.faq-accordion__item, .faq-accordion__trigger, etc.) regardless of
  whether the markup came from PHP or a Custom HTML block.
- template-parts/editorial-breadcrumb.php and
  template-parts/legal-article-layout.php are no longer used by any PHP
  file after this change (their markup is now baked directly into the
  blocks below). They're left in the theme in case you want to revert.
